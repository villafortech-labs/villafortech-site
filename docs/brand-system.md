# Criterio vivo on the web

The source of this design is Roberto Villafuerte’s approved Criterio vivo manual, edition 6 September 2026. The website was designed from scratch with new layouts, while retaining the existing project evidence, profile facts, localized routes, contact links, and printable résumé.

## Visual decisions

- Paper is the main surface; forest anchors the selected case study and closing sections; sage distinguishes the engineering practice section.
- The homepage opens in Manrope Bold and continues in Instrument Serif. Body copy uses Manrope; technical code retains a monospace font.
- Original outlined signatures are used at their intended proportions and minimum sizes. The favicon uses the approved micro artwork.
- Photographs keep their original colors, without decorative overlays or filters.
- Native HTML navigation, visible focus, responsive layouts, reduced motion, and local fonts support access without a client framework.

## Assets and licenses

The SVGs in `public/brand/` are copies of the approved outlined brand assets. The font folders retain the original SIL Open Font License files. The original brand source files and photographs remain preserved in the brand workspace.

## Content and publishing

AI Engineer is the public identity. The site leads with inspectable work and an invitation to exchange ideas. Employment titles and case-study evidence boundaries are unchanged. Existing English and Spanish routes are both retained.

Run `npm run verify` before publishing. Push the verified commit to the repository’s existing `master` branch to use its automatic deployment.
